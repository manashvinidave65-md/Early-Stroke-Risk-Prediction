# Project Visualizations

This directory contains visualizations generated during the Early Stroke Risk Prediction project.

## Exploratory Data Analysis

- Stroke and non-stroke class distribution
- Age distribution
- Age comparison by stroke status
- Average glucose level distribution
- BMI distribution
- Correlation heatmap

## Model Evaluation

- XGBoost feature importance
- Confusion matrix

The visualizations are generated using Python, Matplotlib and Seaborn in Google Colab.

These graphs help explain dataset characteristics, class imbalance, feature relationships and machine learning model performance.

Additional visualizations will be added during final project development.
